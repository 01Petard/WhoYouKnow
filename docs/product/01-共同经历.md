# 01 · 共同经历

**状态** 首版已验收

**依赖** 联系人档案  
**使用场景** 想起一场活动，却记不全当时有哪些人在场。

## 首版范围

- 在「共同经历」新建事件。填标题、发生日期，选择一位或多位联系人。地点和备注可选。
- 从菜单按日期浏览。用标题、地点、备注或参与人的名字搜索。
- 打开事件可查看参与人、编辑或删除。点击参与人可回到联系人档案。
- 在联系人档案显示参加过的事件。点击事件回到同一份记录。

## 数据与规则

- 一次经历只存一条事件。事件保存稳定编号和参与人的联系人编号。
- 同一个联系人在同一事件里出现一次。事件标题相同仍可独立存在。
- 移除参与人只解除该事件的关联。删除联系人时保留事件和其他参与人。全员移除后，事件保留在时间线，并显示暂无参与人。
- 编辑日期会重排事件。事件的发生日期与联系手记的日期分别保存。
- 后续候选包括连续多天的经历和附件。

## 验收

- 创建一场三人活动。任意一位参与人的档案均能打开同一事件。
- 修改一次备注，三个档案链接都指向更新后的内容。
- 删除一位联系人后，另两位仍能查看事件。删除事件后，两份档案的入口一起消失。
- 使用 JSON 导出与恢复后，事件及其参与人对应正确。

## 实施结果

- 桌面从侧栏打开「共同经历」。移动端从底栏「工作台」进入。事件详情可直接打开或从联系人档案进入。
- 生产构建通过。Edge 隔离数据验证覆盖三人事件录入、同一记录回链、编辑、四种搜索、删除和 JSON 恢复。375 像素宽度下可从底栏打开恢复的事件。
- 数据流程测试覆盖旧备份兼容、离线重试、并发编辑合并与参与人引用清理。
