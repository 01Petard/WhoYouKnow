# 05 · 礼尚往来

**状态** 待实现  
**依赖** 联系人档案  
**使用场景** 想想起谁帮过自己，或找到还没兑现的承诺和待准备的礼物。

## 首版范围

- 「礼尚往来」分为「待办」和「已发生」。可按联系人、类别和方向查看。
- 已发生的条目填写联系人、日期、内容，选择「帮助」或「礼物」，方向为「收到」或「给出」。
- 待办填写要做的事，可选计划日期。支持修改、取消和完成。
- 联系人档案显示该联系人对应的往来记录。可从档案返回完整列表。

## 数据与规则

- 已发生的条目使用实际发生日期。待办使用可选的计划日期。
- 标记完成时确认实际发生日期。同一条待办安全地转为已发生记录，重复提交仍只保留一条。
- 取消的事项可从历史查看，可重新打开。已发生记录支持编辑与删除。
- 删除联系人时保留往来条目，人物位置显示「档案已移除」。记录仍保留类别、内容和日期。
- 首版内容使用描述与日期。偏好清单、礼物图片和与联系计划的联动留作后续候选。

## 验收

- 记录一条「收到的帮助」和一条「待准备的礼物」。相应筛选可分别找到两条。
- 将礼物待办标记完成后，待办清单移除该项，已发生列表保留实际日期。
- 删除联系人后，原往来记录仍可读。重新打开应用后状态保持。

## 实施交接

首版可直接实施。优先验证待办完成与已有历史记录的持久化。
