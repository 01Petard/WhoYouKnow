# 06 · 关系回顾

**状态** 首版已验收

**依赖** 联系手记、[共同经历](01-共同经历.md)  
**使用场景** 年底回看这一年和哪些人重新有了交集，并留下一份自己的年鉴。

## 首版范围

- 在「关系回顾」按年份查看。默认选当前年，可切换有记录的往年。
- 展示该年有手记的联系人数、手记条数和共同经历条数。每项可打开来源列表。
- 显示重新联系的人。用户可将手记和事件选入一份回顾，添加标题和自己的短评。
- 导出前预览。可逐项选择是否包含原始手记正文。默认导出 Markdown 文件。

## 数据与规则

- 以手记记录的联系日期和事件发生日期归入年份。联系人数按联系人编号去重，手记和事件各按自身编号统计。
- 首版以 180 天为间隔。同一联系人的两次相邻手记间隔达到该值，且第二次落在选中年份，就列作一次重新联系。此阈值在实现时作为产品默认值确认。
- 统计跟随源数据。选编保存对源记录的引用和用户写的短评。来源移除时，保留短评并提示来源已移除。
- 导出文件保存在用户选择的位置。回顾和选编随 JSON 完整备份保存。
- 自定义人生阶段、长周期对比和打印版留作后续候选。

## 验收

- 用跨年手记验证年份归属。一个人同年有三条手记时，人数计一、手记计三。
- 验证跨年的联系间隔能产生选中年份的重新联系结果。首次手记只按普通联系统计。
- 选择两条记录并添加短评。关闭原文选项后，导出保留用户短评和选中的基本信息。

## 实施结果

- 每年可保存一份选编。重新联系默认使用 180 个自然日。同日多条手记各计一条，联系人数按编号去重。
- Edge 隔离数据验证覆盖年度统计、跨年间隔、原手记跳转、保存选编、Markdown 下载、来源删除后保留短评，以及 375 像素宽度的入口。生产构建通过。
- 数据流程测试覆盖备份恢复、同年首次并发保存及逐条控制原文。手记原文默认从导出中省略。
