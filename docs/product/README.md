## 共用规则

- 当前产品能力见 [README](../../README.md)。各规格中的首版范围是开发计划。
- 继续沿用单用户、本地文件和浏览器暂存模式。记录和选择由用户发起。发消息、邀请、引荐和联络由用户亲自完成。
- 对联系人、事件等对象使用稳定编号。联系人改名后更新引用显示。删除联系人时按各规格说明处置关联记录，并在确认前说明影响。
- 持久化数据纳入 JSON 完整备份与恢复。实现时验证旧数据读入、离线暂存、多页并发和失败重试。CSV 联系人表沿用现有职责。
- 涉及「今天」「本年」的日期按使用设备的本地日历判断。需要过去状态时保存明确输入或实际记录，展示时注明数据依据。
- 核对本机保存流程和空状态。每期至少验证一次关键交互、备份往返、旧数据兼容和移动端入口。
- 完成一个功能后，在该规格及本表记录状态，附提交或验收证据。超过首版的取舍在动手前写回对应文档。
