# components/

> L2 | Parent: [../AGENTS.md](../AGENTS.md)

- `Alert.tsx` 展示页面内持续提示。
- `BackupPanel.tsx` 在设置和首次启动页预览并恢复备份。
- `ContactHistory.tsx` 显示并编辑联系人档案中的手记。
- `CircleEditor.tsx` 编辑圈子名称与分组成员。
- `EmptyState.tsx` 展示空状态与下一步操作。
- `DateField.tsx` 提供手输日期与站内月历。
- `FacetFilters.tsx` 按维度分行展示可多选的筛选选项。
- `Layout.tsx` 装配响应式导航、路由内容与保存状态。
- `Logo.tsx` 加载导航与欢迎页共用的品牌图标。
- `Modal.tsx` 提供对话框、焦点管理与操作确认。
- `NetworkGraph.tsx` 渲染关系网和图例。按分组时标注全部有成员的分组。
- `PersonCard.tsx` 提供共用头像及目录行。目录行展示分组、圈子和标签。
- `QuickSelect.tsx` 提供站内单选、多选与快捷下拉。
- `RelationshipBadge.tsx` 展示联系人重要标记。
- `Toast.tsx` 提供短时反馈，保存成功提示等待文件写入。
