# pages/

> L2 | Parent: [../AGENTS.md](../AGENTS.md)

- `CategoriesPage.tsx` 主区管理分组、圈子和标签。待分类区提供快捷分配。
- `CircleDetailPage.tsx` 展示圈子成员及其分组来源。
- `ContactJournalPage.tsx` 按月展示手记和往年今日。
- `DataPanel.tsx` 装配备份面板和联系人 CSV 流程。
- `ExchangesPage.tsx` 分列往来待办、已发生与取消历史，待办原地转为实际记录。
- `ExperiencesPage.tsx` 展示共同经历时间线和详情，编辑事件及参与人。
- `GroupPage.tsx` 按分组浏览并调整成员。
- `IntroductionsPage.tsx` 编辑引荐三方和进展，查询有记录可追溯的路径。
- `NetworkPage.tsx` 切换图谱分类、事务联系人显隐及搜索定位，并提供选中联系人的完整资料。
- `PeoplePage.tsx` 提供姓名查询、首字母多选、分类多选、全部、社交和事务目录。按联系人分组推导目录的圈子列。
- `PersonDetailPage.tsx` 并列展示联系活动与档案资料。可打开此人的共同经历、引荐和往来。
- `PersonFormPage.tsx` 通过分区表单新建或编辑联系人和我的资料。新建时选择社交或事务目录。可选字段直接显示。新建遇到同名时，可新增或更新指定联系人。
- `ProfilePage.tsx` 展示我的资料和分类概览。
- `ReviewsPage.tsx` 展示年度来源和重新联系。可编辑选编、预览与下载 Markdown。
- `SelfSetupPage.tsx` 新建、迁移或从备份恢复我的资料。
- `SettingsPage.tsx` 展示数据文件状态、备份和导入导出入口。
