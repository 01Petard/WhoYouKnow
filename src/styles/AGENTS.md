# styles/

> L2 | Parent: [../AGENTS.md](../AGENTS.md)

- `global.css` 声明主题、基础组件和页面样式的导入顺序。
- `tokens.css` 定义颜色、字体、间距和交互反馈 Token。
- `base.css` 提供按钮、字段、月历、空态、弹窗和提示样式。
- `shell.css` 定义桌面侧栏、移动端导航与工作台入口。
- `directory.css` 定义联系人目录、筛选和概览。窄屏将分类排在姓名下方。
- `exchanges.css` 定义礼尚往来的筛选和表单布局。
- `network.css` 定义普通和全屏关系网的画布、控件、图例和联系人资料位置。
- `contact-profile.css` 定义联系人详情的身份区、联系活动与资料布局。
- `cities.css` 定义城市目录、档案城市表单与行程布局。
- `experiences.css` 定义共同经历和引荐共用的时间线与档案回链，并提供参与人选择和引荐路径布局。
- `projects.css` 定义项目状态切换、成员、待办及逾期展示。
- `person-pages.css` 定义档案、录入表单和欢迎页。
- `journal.css` 定义手记时间线、回顾卡和档案列表。
- `organize.css` 定义站内下拉、分类主区与待分类侧栏，以及成员和数据设置页。
